## Ограниченное повторное использование фактов

Открытая лицензия региональной базы и retailer сайта не установлена; CC0 USDA
на них не переносится. Принято ограниченное использование общедоступных числовых
наблюдений с обязательной атрибуцией и минимальным проверяемым фрагментом
заголовков/единиц/SKU. Это собственное решение о фактическом цитировании для
локального расчёта, не заявление о полученной от издателя лицензии на базу.
Полные XLS/HTML, фотографии, отзывы, дизайн и тексты описания остаются только
локальными материалами исследования `.tmp`; в приложение не копируются.
Публичная публикация полного чужого набора этим решением не разрешается.
[Правила ВкусВилла](https://vkusvill.ru/pravila/) просмотрены; они описывают общение
и не приняты за лицензию открытых данных. Каждая строка имеет reuse disposition.

Исследованы альтернативы `.tmp/phase2-price-discovery.md`: Open Prices доступен,
но обнаружены расхождения API с фото/базисом. Эти записи не импортируются.
Повторные известные TLS failures Росстата не использовались, проверка TLS и
контроль доступа не отключались. Оплачиваемые API и новые app dependencies не нужны.

## Safety

`safety.snapshot.json` хранит для каждого точного USDA профиля исходную запись
и категорию, hash и rationale. Для однокомпонентных растений/соли/сахара разрешены
только `no-fish` (включая исключение морепродуктов) и `vegetarian` по документированной
идентичности/происхождению. Это не аллергенная гарантия конкретной упаковки.
`gluten-free`, `lactose-free`, `halal` остаются unknown: нельзя автоматически
подтвердить производственную линию, маркировку, добавки, следы или сертификацию.
Нет универсальных разрешающих allergen facts. Запрос неподтверждённого ограничения
не получает успешного меню из этих профилей. Никаких сертификатов не выдумано.

## Корпус и проверка

Рецепты — оригинальные авторские формулы и русские инструкции MealPlan,
без заимствования внешних рецептов/фото. Проверка состава, различий и реальной
генерации будет записана здесь после завершения второго задания. Кухонная
проверка, вкус и медицинская полноценность не утверждаются.
