## Pattern Assignments

### Historical release и current acceptance

Основной аналог `src/data/catalog.ts`, строки 1–38 и 44–98. Существующие imports показывают фактическую границу offline manifests и runtime adapter.

```typescript
import foodSnapshot from '../../data/sources/food.snapshot.json';
import priceSnapshot from '../../data/sources/prices.snapshot.json';
import safetySnapshot from '../../data/sources/safety.snapshot.json';
import { createLocalCatalog, validateCatalog } from '../adapters/catalog';
import { immutableSnapshot, sameSnapshot } from '../domain/appliedSettings';
```

Текущий release фиксируется выражением из строки 37.

```typescript
export const bundledCatalog: Catalog = immutableSnapshot({ version: 'mealplan-2026-10-28-1', foods, recipes });
```

Source acceptance использует два независимых слоя. `validateCatalog(input)` проверяет структуру, затем `sameSnapshot(checked.catalog, bundledCatalog)` проверяет полный compiled corpus. Для новых данных сохранить оба слоя, выделив исторический builder без изменения его результирующих фактов. Current corpus может включать исторические объекты и новые профили.

В строках 49–88 source gate привязан к единственному archive SHA, четырём USDA nutrient IDs, дате `2026-10-28`, двум положительным safety facts и прежним неизвестным сертификатам. Новые источники требуют собственных правил по типу источника. Каждая запись должна сопоставлять ID, исходный базис, decimal strings, hash и runtime значения. Удаление source gate делает недоверенный вход trusted. Добавление новых продуктов в старую таблицу с прежними assumptions создаёт неверные факты.

Production-port pattern из строк 93–98 переиспользуется для каждого compiled release.

```typescript
const accepted = validateBundledCatalog(bundledCatalog);
const delegate = accepted.then(result => createLocalCatalog(result.status === 'loaded' ? result.catalog : null));
export const bundledCatalogPort: CatalogPort = {
  async load() { return accepted; },
  async lookup(productId, profileId) { const result = await accepted; return result.status === 'invalid' ? result : (await delegate).lookup(productId, profileId); },
  async evaluate(ingredient) { const result = await accepted; return result.status === 'invalid' ? result : (await delegate).evaluate(ingredient); },
};
```

`src/data/sources.test.ts`, строки 4–34, хранит независимые исходные литералы и hash checks. Новые source tests должны иметь собственные ожидаемые значения из RESEARCH, а исторический набор сохраняет исходные assertions. Не выводить expected через production mapping.

### Trusted versions и generation dispatch


```typescript
const trusted = versions.get(catalog.version);
```

Реестр формируется только программно через `createTrustedCatalogRegistry(catalogs)`. Конструктор структурно проверяет каждый релиз, запрещает повтор версии и хранит detached/frozen copies. Требуется зарегистрировать historical и current releases. Persisted JSON проходит сравнение с этими releases.

`createLocalGeneration(catalog: CatalogPort, options: GenerationOptions = {}): GenerationPort` уже принимает проверенный adapter через injection. Существующий adapter detach-ит request до первого await, проверяет `targetCount` 1–3 и exclusions до 12, поддерживает cancellation, macrotask yield и общий deadline до 30000 ms.

```typescript
const loaded = await catalog.load();
const checked = validateCatalog(loaded.catalog);
if (!sameSnapshot(checked.catalog, validated.inputs.catalog)) return { status: 'error', error: {
```

### Новые рецептуры и product search

Основной аналог `src/data/recipes.ts`, строки 1–20. Helper использует точные quantities и profile IDs.

```typescript
const profiles = new Map(foodSnapshot.records.map(food => [food.productId, food.profileId]));
type Amounts = Readonly<Record<string, number>>;
function author(id: string, name: string, slots: readonly MealSlot[], minutes: number, amounts: Amounts, steps: readonly string[]): Recipe {
  const ingredients: Ingredient[] = Object.entries(amounts).map(([productId, grams]) => {
    const profileId = profiles.get(productId);
    if (!profileId) throw new Error(`Unacquired ingredient: ${productId}`);
    return { productId, profileId, quantity: { amount: decimal(String(grams)), unit: 'g' } };
  });
  return { id, name, slots, cookingMinutes: minutes, baseServings: decimal('2'), ingredients, steps,
    source: { sourceId: 'mealplan-original-recipes', recordId: id, release: '2026-10-28-1',
      url: 'https://mealplan.invalid/original-recipes', license: 'MealPlan original authored content' } };
}
```

Новый recipe module принимает общий registry профилей или свой явный mapping, задаёт собственный release, сохраняет исходные порции и создаёт полный original content. Current state food профилей задаётся source-specific значениями для raw, dry, ready/drained и готовых молочных продуктов. Historical helper и его 52 результата остаются фактически прежними.

Метаданные family/group выносятся в compiled sidecar keyed by catalog version и recipe ID, аналогично presentation sidecar в `src/data/recipeMedia.ts`. Это позволяет добавить ranking metadata без изменения persisted `recipeSnapshot`. Реального family sidecar в проекте пока нет.

Product contract находится в `src/adapters/products.ts`, строки 5–16.

```typescript
export interface ProductName { id: string; name: string; synonyms: readonly string[]; allowedUnits: readonly Unit[] }
export interface ProductCatalogPort { search(query: string): Promise<readonly ProductName[]> }
```

Generic `egg` разрешает только `pcs`, а chicken/tvorog уже имеют устойчивые IDs и массу. Для новых яичных рецептов добавить массу в permitted input units и сохранить прежние `pcs` draft values. Конверсия generic egg pcs→g не имеет достаточного evidence. Canned drained beans требуют отдельных product IDs от сухих beans. Поиск использует NFC, trim и ru lowercase. Product names не являются safety-фактами.

### Diverse starts и мягкое ранжирование

Основной аналог `src/domain/generatePlan.ts`, строки 20–40, 48–74, 100–139 и 174–224. Pure generator возвращает progress через yield, адаптер владеет временем.

```typescript
export const SEARCH_LIMITS = Object.freeze({ beamWidth: 32, maxEvaluations: 512, evaluationCeiling: 20000,
  maxTransitions: 200000, batchSize: 128, exhaustiveSize: 256 });
```

`variantFingerprint` учитывает date, slot, recipeId и нормализованные servings, сохраняя семантическую уникальность. Score использует lexicographic exact Rational comparisons. Прежние precedence expiring pantry и явного target берутся из `score`, строки 48–74. Новые family/group terms добавляются в существующий soft score, сохраняя hard admission и hard purchase budget.

```typescript
const key = JSON.stringify(ids);
if (seen.has(key)) return undefined;
seen.add(key); evaluatedCandidates++;
const variant = makeVariant(inputs, ids), result = projectPlan(inputs, variant);
```

Все полные diverse starts должны проходить этот же evaluation path и расходовать общий budget. Существующий non-exhaustive путь начинает cheapest baseline и делает два rounds single-slot substitutions. Из-за этого новые animal-food candidates могут остаться вне обычного меню. Новые balanced/seed-rotated starts создаются только из admitted candidates. Недоступные при restrictions семьи не создают требования нарушить ограничения.

Synthetic Catalog tests не имеют family sidecar. Fallback для них должен сохранять действующие deterministic behaviors. `SEARCH_EXHAUSTED` сохраняет отдельный смысл от доказанной `BUDGET_TOO_LOW`. Новый ассортимент не даёт оснований повысить deadline без измерения.

Resolver сейчас поддерживает одну версию. Вынести association table по версии и сохранить публичный resolver signature, чтобы RecipeImage/route callers продолжили работать. Audit уже проверяет ID, local path, provider/prompt/date/terms/originalArtifact, visualReview, realpath containment, PNG IHDR, ratio4:3, hash и duplicate content. Сохранить эти проверки при расширении CLI.

```javascript
const file = path.resolve(root, `public${row.path}`);
const contained = fs.realpathSync(path.join(root, 'public/recipes')) + path.sep;
if (!fs.realpathSync(file).startsWith(contained)) throw Error(`Path escapes assets: ${id}`);
```

Новые генерации проходят существующий workflow native outputs и provenance. Разумные партии остаются возобновляемыми по ledger. Внешний вызов, hash и visual acceptance фиксируются фактически. Остановка по quota сохраняет уже полученные outputs и missing IDs.

## Shared Patterns

- Доменные quantities остаются Rational. `evaluateIngredient` и `projectPlan` используются для новых foods и всех экранов. Одноразовое pantry allocation остаётся в projection.
- Safety проходит отдельные evidence-specific facts. Fish получает отрицательные `no-fish`/`vegetarian` facts, animal products отрицательный `vegetarian`, egg/dairy могут иметь подтверждённый identity-based vegetarian. Allergen/certification неизвестное остаётся явным.
- Source estimates содержат primary input, фактический scope, target Санкт-Петербург, дату и derivation. Пользовательский `CalculationNote` сохраняет краткое «Цены и КБЖУ примерные». Технический provenance хранится в данных и документации.
- Импорты используют относительные пути и `import type`. Новые dependencies для перечисленных изменений не нужны.
- Тесты источников хранят независимые literal oracles. Browser acceptance читает настоящий saved envelope и сравнивает menu→recipe→shopping→reload.
- `e2e/phase03-recipes.spec.ts`, строки 7–48, показывает real one-click generation, извлечение выбранного instance из storage, точный contextual route и equality raw bytes. `e2e/phase03-media.spec.ts` проверяет декодирование local hero и отсутствие внешних image requests. Эти patterns подходят новому `e2e/catalog-expansion.spec.ts`.
