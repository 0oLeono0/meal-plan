# Фаза 5 — решения перед планированием

Решения приняты автономно после запроса «Продолжи». Полное поведение описано в `05-CONTEXT.md`.

| Вопрос | Решение |
| --- | --- |
| C-03, подписка на изменения запасов | Покупки обновляются после подтверждения правки запасов. «Пересчитать» запускает отдельный подбор блюд, «Позже» оставляет состав плана. |
| Q-07, Q-16, количества | Пустое число, несовместимая единица и неподтверждённая масса дают нулевое покрытие. Известное совместимое количество используется один раз. |
| Q-11, связь с мастером | Самостоятельный холодильник с источником первого наполнения. Черновик мастера можно применять в рамках отдельного меню, простое редактирование и пропуск холодильник не меняют. |
| Q-06, Q-08, сохранённые варианты | Покрытие вычисляется заново для каждого варианта. Превышение из-за уменьшения запаса явно отображается. Для новой генерации и правок сохраняются строгие проверки. |
| Q-10, приоритет остатков | Мягкий приоритет первых одного или двух дней. Подбор и пересчёт ничего физически не списывают. |
