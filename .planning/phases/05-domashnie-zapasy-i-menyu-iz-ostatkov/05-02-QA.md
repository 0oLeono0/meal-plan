Пустой подтверждённый список хранится отдельной записью. Если уже виденная запись исчезает из хранилища, открытая вкладка показывает ошибку чтения. При холодном запуске отсутствие ключа означает исходное состояние холодильника. Приложение записывает пустой список при удалении последней строки.

Адаптер сравнивает прочитанные исходные байты с текущими перед записью. Между отдельными вызовами разных вкладок нет общей атомарной операции сравнения и записи. Полная межбраузерная проверка предусмотрена в плане 05-06.
