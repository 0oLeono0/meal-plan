# Фаза 5, план 04 — источники запасов при запуске меню

Чистый шаг мастера предлагает текущие запасы. При явной правке мастер сохраняет отдельный ввод для следующего меню. Подтверждённый холодильник определяет снимок быстрого старта, включая пустой список.

Сохранённое меню использует авторский снимок мастера до фактической смены редакции холодильника. Затем покупки и бюджет пересчитываются для всех вариантов. После перезагрузки, правки блюда и смены варианта сохраняются редакция склада и индивидуальные основания бюджетного допуска. При повреждении записи пользователь может повторить чтение. Устаревшее подтверждение запуска сохраняет прежнее меню.
