# Фаза 5, план 03 — бюджет и сохранённые варианты

Сохранённое меню остаётся доступным после изменения запасов. Превышение выводится на основе текущей закупки. Один вариант можно допустимо изменить, пока другой требует пересмотра. Доверенная основа допуска сохраняется для конкретного варианта и проходит повторный расчёт при загрузке. Генерация сохраняет строгий лимит.

Изменение запасов закрывает прежние альтернативы и отклоняет ещё не записанный результат. Подтверждённая запись остаётся доступной. Chromium прошёл 9/9, а окончательный целевой Vitest после исправления регрессии пересборки — 150/150. [Отчёт проверки](05-03-QA.md)
