Тесты проверяют ×0.5 и ×2, массу каждого ингредиента, nutrition и стоимость. Отдельный повторный набор B6/S4 требует440г яйца и560г молока. При запасах150г и200г покупки составляют290г и360г. Stock расходуется один раз.

У яйца сохранён прежний ввод pcs и добавлены g/kg. Generic pcs не получает коэффициента массы. Старый raw draft с молоком ml сохраняет исходное значение и получает существующую ошибку совместимости при применении. Независимый pantry snapshot с pcs/ml даёт INCOMPATIBLE_PANTRY_UNIT в projection. Milk search предлагает взвешенную массу. Generic ml↔g и dry↔canned conversions отсутствуют. Сухие запасы с ID chickpea/bean не уменьшают покупки chickpea-canned/bean-canned.

## Граница доверия

Каждая запись хранит literal source strings, reference, state, identity, sourceVersion и hash. Release hashes отдельно фиксируют точный набор записей56 и68. Проверка отклоняет изменения scope, edible basis, assessmentDate, quantity, label values/license, drained ID, выбранной цены и hash. Сохранённый snapshot принимается только при совпадении с compiled каталогом соответствующей версии. Nutrition, цены и identity safety имеют разные source attribution. Unknown halal/gluten/lactose/allergen guarantees сохранены.
