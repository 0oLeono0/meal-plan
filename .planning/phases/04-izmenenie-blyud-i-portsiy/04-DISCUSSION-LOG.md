# Фаза 4 — решения перед планированием

По запросу «Продолжи» решения приняты самостоятельно с опорой на фронтенд-ТЗ, исходные вопросы и уже принятые правила MealPlan. Файл контекста фиксирует рабочие решения агента.

| Вопрос | Выбранное поведение |
| --- | --- |
| Q-04, база дельт | Изменение общей закупки с учётом запасов и изменение КБЖУ по конкретному приёму. В списке альтернатив показываются деньги и калории с подписью базы. |
| Q-05, семейные порции | Абсолютные множители от применённого числа семейных порций. Смена масштаба относится к одному вхождению. |
| Q-08, мало вариантов и бюджет | Показать столько допустимых вариантов, сколько найдено, максимум пять. Сохранить жёсткий бюджет и объяснять установленную причину отказа. |
| Q-06/Q-09, связь с другими данными | Редактировать только активный вариант, сохранять правки после перезагрузки и добавления нового варианта. Автоматические покупки берутся из расчёта плана. Ручные покупки рассматриваются в фазе 6. |
| Q-16, точность | Переиспользовать действующие точные расчёты, денежное округление и форматирование. Не проводить сравнение с бюджетом по округлённым значениям. |
