## Границы доказательств

Первый эксперимент с `context.setOffline(true)` после52 переходов online **не прошёл**: dev Vite отдаёт `Cache-Control:no-cache`, Chromium повторно проверяет первый PNG и получает `net::ERR_INTERNET_DISCONNECTED`. Это не поддержка полной автономной загрузки приложения. Пробная test-only SW регистрация тоже не прошла (worker fetch получил HTML); она удалена, не вошла в поставляемый тест и не считается evidence. Ни PWA, ни runtime cache, ни холодная загрузка без локального сервера этим планом не реализованы. Принятый gate соответствует action плана: блокировка внешних ресурсов при доступном localserver. Никакие тестовые bytes/SW не подменяют hero в принятом прогоне.

Generated output регулируется условиями провайдера, а не выдуманной CC0-лицензией. `effectiveDate` — дата invocation, не дата ревизии условий. [OpenAI terms](https://openai.com/policies/row-terms-of-use/); эксклюзивность не обещается. Подпись в UI: «Фотоиллюстрация создана с помощью ИИ; внешний вид блюда может отличаться». Состав/КБЖУ берутся из структурированного каталога, не из изображения. Кухонная/медицинская полноценность не утверждается. Пользовательская визуальная оценка остаётся end-of-phase UAT.
