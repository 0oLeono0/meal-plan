# Защитная проверка редактирования блюд

Независимый аудит подтвердил меры для всех 14 уникальных угроз из пяти планов. Новых угроз в итогах планов не зарегистрировано.

| Угрозы | Меры и результаты |
| --- | --- |
| T-04-01, T-04-06 | Команда проверяет вариант, дату, слот, рецепт, ожидаемое вхождение или пустоту и актуальность редакции. Новый идентификатор не восстанавливает ссылку на удалённое блюдо. |
| T-04-02, T-04-07 | Допуск использует доверенный каталог, общие жёсткие фильтры, разрешённые множители и точный бюджет всей закупки. |
| T-04-03, T-04-12 | Поиск разбит на отменяемые пакеты, видимый список ограничен пятью допустимыми вариантами. Проверены подстановка длинных названий и доступность закрытия. |
| T-04-04, T-04-05 | Кодек проверяет полноту координат, сохранённый каталог и ограничение UTF-8. Новый формат поддерживает явно пустые слоты, результат генератора остаётся полным. |
| T-04-08, T-04-09 | Маршрут предварительного рецепта привязан к текущей операции и конкретному вхождению. Прямой и устаревший адрес не дают править меню. |
| T-04-10 | Контроллер и адаптер проверяют актуальность записи. Конфликт исходных байтов останавливает перезапись и требует обновления. Тест реального адаптера подтвердил, что успешно записанная правка признаётся сохранённой на границе срока (`c246563`). |
| T-04-11 | Пользователь может закрыть поиск. Завершение отменённой операции не меняет меню. Предусмотрен возврат фокуса при скрытии карточки (`ef4493b`). |
| T-04-13 | Хранилище повторно валидирует входные данные. Реальные браузерные сценарии покрывают отказ записи, откат, повтор и наблюдаемый конфликт. |
| T-04-SC | `package.json` и `package-lock.json` совпадают с состоянием до фазы 4. |

Сравнение байтов защищает от изменения записи, уже доступного для чтения. Синхронная запись localStorage не предоставляет общей атомарной операции сравнения и записи между вкладками.
